## 🔍 数据说明

- **数据来源**：东方财富网公告（AkShare抓取）+ 巨潮资讯网PDF
- **收录范围**：公告标题含"补税/补缴税款/缴纳税款/税务事项"等关键词
- **2026年数据**：98家公司，涉及20个省市，补税总额约85.6亿元
- **2025年数据**：73家公司，约20亿元
- **金额来源**：公告原文 + PDF文本提取 + 人工修正
- **更新频率**：随新公告发布持续补充

## 📈 核心发现

| 指标 | 2025年（全年） | 2026年（1-8月） |
|------|:----------:|:------------:|
| 公告公司数 | 73家 | **98家** |
| 补税总额 | ~20亿元 | **~85.6亿元** |
| 亿元级公司 | 3家 | 18家 |
| 最大单笔 | 山东黄金 7.38亿 | 北大荒 14.1亿 |

2026年补税呈现显著地域集中特征：
- **广东15家、江苏14家、浙江9家**居公司数量前列
- **湖南17.8亿、黑龙江14.5亿**居金额前列（北大荒单笔14.1亿）
- 珠三角+长三角公司占总量超40%

### ⚠️ 重大风险案例

- **华邦健康**（重庆）：两次补税，子公司沈阳新马药业被认定**虚开发票**，涉及刑事风险
- **北大荒**（黑龙江）：14.1亿单笔最大，农业税收优惠口径争议
- **包钢股份**（内蒙古）：连续两年补税

- 数据库：JSON / Excel / CSV
- 托管：GitHub Pages
- PDF提取：PyPDF2
